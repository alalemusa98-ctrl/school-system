# الدليل الشامل والنظرة العامة للمشروع (Master Project Overview & Vision)

> **اسم المنظومة:** نظام إدارة المدرسة المرتكز على الطالب (Libyan Student-Centered School Management System)  
> **الإصدار المعماري:** V1.0 (MVP Foundation) مع الجاهزية الكاملة للترقية إلى V2.0  
> **البيئة المستهدفة:** مدارس مرحلة التعليم الأساسي (الصفوف 1 إلى 9) في دولة ليبيا

---

## 1. فكرة المشروع والرؤية الأساسية (Core Concept & Vision)

يقدم المشروع منصة ويب تعليمية متكاملة مصممة لإعادة ابتكار تجربة المتابعة المدرسية اليومية. بدلاً من الاعتماد على مجموعات المحادثات العشوائية (مثل WhatsApp و Viber) أو أنظمة إدارة التعلم المعقدة (LMS) التي لا تناسب أطفال المدارس الابتدائية والإعدادية، يقدم النظام تجربة رقمية فائقة السلاسة ترتكز على مبدأ **"التمحور حول الطالب" (Student-Centric Paradigm)**.

تعتمد المنظومة تصميماً مستوحى من تطبيقات هواتف **Apple iOS** الحديثة (الزجاج الضبابي، البطاقات المتراكبة، والجزيرة التفاعلية)، مما يجعل متابعة الواجبات، مواعيد الامتحانات، الحلول النموذجية، والجدول الأسبوعي تجربة بديهية وممتعة للأطفال وأولياء الأمور دون أي حواجز تقنية.

## 4. نطاق العمل للنسخة الأولى (V1 Scope - MVP Deliverables)

تتضمن النسخة الأولى (V1) الأساسات الوظيفية المتينة للمنظومة:
1. **الهيكل التعليمي المتدرج:** تثبيت الصفوف الأساسية الـ 9، تقسيم كل صف لشعب (5أ، 5ب)، وتوحيد المواد المقررة لكل صف.
2. **سجلات وقيد الطلاب:** تسجيل الطلاب برقم جلوس فريد وتوليد كود دخول سري، مع ربط الطالب بشعبته الدراسية.
3. **إدارة الكادر التدريسي:** إنشاء حسابات المعلمين بكلمات مرور مشفرة بـ `Bcrypt`، وإسناد المواد والشعب لكل معلم.
4. **نظام المهام والتقييمات المدرسية:**
   * نشر الواجبات المدرسية لشعبة محددة مع عنوان، وصف، تاريخ تسليم، وملف مرفق (PDF / صورة حتى 10MB).
   * نشر الامتحانات والاختبارات الشهرية المجدولة مع النماذج الاسترشادية.
   * **الحل النموذجي الفوري:** إمكانية إرفاق نص وملف الحل النموذجي المعتمد يظهر فوراً للطالب عند تفعيله (`has_solution = 1`).
5. **بناء واستعراض الجدول الأسبوعي:** شبكة تفاعلية لتوزيع الحصص الـ 6 عبر أيام الأسبوع الـ 5 (30 حصة أسبوعياً لكل شعبة) بنمط `Upsert`.
6. **بوابة الدخول الموحدة:** شاشة `/login` بتبديل كبسولي فوري للأدوار الثلاثة وتوليد جلسات JWT صالحة لمدة 7 أيام.

## 5. حدود النطاق - المؤجل للنسخة الثانية (Out of Scope / V2 Vision)

تم استبعاد الخصائص التالية عمداً من النسخة الأولى V1 لتسريع إطلاق الـ MVP وضمان بساطة الاستخدام:
* ❌ **نظام الفترات الدراسية (Active Periods):** أرشفة الفترات المنتهية تلقائياً مؤجلة لـ V2.
* ❌ **الجدولة الزمنية للحلول النموذجية (Scheduled Release):** الحل في V1 يظهر فورياً بمجرد النشر ولا يرتبط بساعة أو تاريخ مستقبلي.
* ❌ **النشر متعدد الشعب (Broadcasting):** الواجب في V1 يُنشر لشعبة واحدة فقط للمهمة.
* ❌ **التسليم الإلكتروني للواجبات من الطلاب (Student Uploads):** واجهة الطالب استعراضية وتوجيهية فقط (Read-Only).
* ❌ **رصد الدرجات وإصدار الشهادات:** مخصص للإصدارات المتقدمة اللاحقة.

## 6. الركائز المعمارية والتصميمية للمنظومة (Architectural Tenets)

```
                            الركائز المعمارية الأساسية
                                        │
    ┌───────────────────┬───────────────┴───────────────┬───────────────────┐
    ▼                   ▼                               ▼                   ▼
┌───────────────┐ ┌───────────────┐           ┌───────────────────┐ ┌───────────────┐
│ الفلسفة       │ │ الأمان الصارم │           │ محول البيانات     │ │ الجلسات       │
│ البصرية       │ │ وعزل البيانات │           │ الهجين المرن      │ │ اللامركزية    │
│ المزدوجة      │ │ Zero-Trust    │           │ SQLite / MySQL    │ │ Stateless JWT │
└───────────────┘ └───────────────┘           └───────────────────┘ └───────────────┘
```

1. **الهوية البصرية المزدوجة (Dual Aesthetics):**  
   واجهة الطالب والمعلم بنمط **iOS Native Glassmorphism** للهواتف، ولوحة الإدارة بنمط **macOS SaaS Dashboard** للشاشات المكتبية.
2. **عزل المستأجر التلقائي (Zero-Trust Tenant Isolation):**  
   حظر الاعتماد على أي مدخلات من العميل لتحديد شعبة الطالب؛ يتم استخراج `sectionId` من التوكن المفكك على الخادم لضمان أمان تام.
3. **محول البيانات الهجين (Multi-Driver DB Adapter):**  
   العمل على `SQLite` للتطوير المحلي السريع بدون إعدادات معقدة، مع إمكانية التبديل إلى `MySQL` للإنتاج عبر تعديل `.env` فقط.
4. **الجلسات اللامركزية (Stateless JWT):**  
   إدارة جلسات سريعة وخفيفة لا تستهلك ذاكرة الخادم مع تشفير كلمات المرور بـ `Bcrypt`.

## 7. معايير النجاح ومؤشرات الأداء (Success Criteria & KPIs)

* ⚡ **سرعة استجابة الـ API:** زمن استجابة أقل من **50ms** لكافة استعلامات الطالب والمعلم.
* 📱 **التجاوب البصري الكامل:** توافق تام 100% مع الهواتف الذكية والأجهزة اللوحية والشاشات المكتبية.
* 🔒 **انعدام تسريب البيانات:** نسبة خطأ 0% في عزل مهام وجدول الطالب عن باقي الشعب والفصول.
* 🎯 **سهولة الاستخدام:** تمكين الطالب من معرفة واجبات اليوم في أقل من **5 ثوانٍ** من فتح التطبيق.
