# دليل ومواصفات واجهة الإدارة الشاملة (Admin Interface & UX Scenarios Specification)

لوحة تحكم إدارية مكتبية متكاملة (Desktop Executive SaaS Dashboard) مصممة وفق نمط أنظمة التشغيل الحديثة (macOS Design Guidelines). تمنح الإدارة المدرسية السيطرة التامة على كافة تفاصيل المؤسسة التعليمية من خلال شاشات عامة، لوحات تفصيلية منبثقة، وملفات شخصية مستقلة لكل طالب ومعلم وفصل.

---

## 1. الهيكل التنفيذي وشريط التنقل العام (Executive Header & Shell)

### أ. الهيدر العلوي وشريط البحث (`header.html`):
* **الشعار والعنوان التجاري (Brand Identity):** أيقونة قبعة التخرج داخل مربع متدرج، عنوان *منظومة إدارة المدرسة*، والنص الفرعي *لوحة التحكم الإدارية الشاملة*.
* **شريط البحث الفوري المركزي (Global Fast Search):** حقل بحث دائري سريع ومحاط بإطار ناعم للبحث اللحظي بالاسم أو الكود عن: طالب، معلم، مادة، أو فصل.
* **جرس الإشعارات التفاعلي (Notification Center):** زر دائري يعلوه مؤشر أحمر بعدد التنبيهات النشطة (مثل غياب معلق، طلب نقل طالب).
* **قائمة مدير المنظومة المنسدلة (macOS Style Floating Dropdown):**
  * كبسولة تحتوي على الرمز التعبيري للمدير، الاسم (*مدير المنظومة*)، والصفة (*المدير العام*).
  * عند النقر: تفتح قائمة زجاجية عائمة تحتوي على:
    * ملخص الحساب والبريد الإلكتروني (`admin@school.edu.ly`).
    * اختصارات سريعة للوحة المفاتيح:
      * `⌘1` ➔ الانتقال للوحة الإحصائيات التفاعلية.
      * `⌘2` ➔ الانتقال للفصول والقاعات.
      * `⌘3` ➔ الانتقال للجدول الدراسي الأسبوعي.
      * `⌘R` ➔ تحديث البيانات الحية فورياً من الخادم.
    * زر تسجيل الخروج الإداري الآمن بالأحمر (`⌥⌘Q`).

### ب. شريط التاريخ وإجراءات الصفحة (`PageActions.html`):
* **كبسولة التاريخ اليومي:** أيقونة تقويم + عرض التاريخ الهجري والميلادي واليوم (مثل: *اليوم: الجمعة، 16 أغسطس 2026*).
* **زر طباعة التقرير الفوري:** زر أبيض بحدود ناعمة مع أيقونة طابعة يربط أمر الطباعة المنسقة للمتصفح (`window.print()`).

### ج. شريط التنقل الفرعي بين الموديولات (Sub-Navbar Tabs):
* كبسولات تفاعلية للتنقل بين الأقسام: `الرئيسية والإحصائيات` | `سجلات الطلاب` | `إدارة المعلمين` | `الهيكل والفصول` | `المواد الدراسية` | `الجدول الدراسي الأسبوعي`.

  * `GET /api/admin/stats` ➔ لجلب الأعداد المحدثة.

## 3. الموديول الثاني: منظومة إدارة وسجلات الطلاب (Student Records & Profiles)

يتضمن هذا الموديول شاشتين أساسيتين: شاشة السجل العام وشاشة الملف التفصيلي للطالب.

### أ. لوحة وسجلات الطلاب العامة (`StudentRecordsPanel.html`):
* **الترويسة وأزرار الإجراءات:**
  * عنوان القسم مع أيقونة التخرج.
  * زر رئيسي بنفسجي: **`+ إضافة طالب جديد`**.
  * زر أبيض بحدود: **`نقل طالب بين الشعب 🔄`**.
* **شريط الفلاتر والبحث اللحظي:**
  * حقل بحث دائري بالاسم أو رقم الجلوس أو كود الطالب.
  * قائمة منسدلة لتصفية الطلاب حسب الصف (جميع الصفوف، الصف الأول، الخامس...).
  * قائمة منسدلة لتصفية الطلاب حسب الشعبة (جميع الشعب، 5أ، 5ب...).
* **جدول بيانات الطلاب التفاعلي:**
  * الأعمدة: `رقم الجلوس` | `كود الطالب` | `الاسم الكامل للطالب` | `الصف الدراسي` | `الشعبة` | `إجراءات الإدارة`.
  * **سيناريو النقر على اسم الطالب:** عند الضغط على اسم أي طالب بالجدول، يتم فتح **شاشة ملف الطالب التفصيلي (Student Profile View)**.
  * أزرار الإجراءات المباشرة لكل صف:
    * زر النقل (`🔄`): يفتح نافذة نقل الطالب السريعة.
    * زر التعديل (`✏️`): يفتح نافذة تعديل بيانات الطالب.
    * زر الحذف (`🗑️`): يظهر رسالة تأكيد الحذف النهائي.

---

### ب. شاشة ملف الطالب التفصيلي (`StudentProfile.html`):
تفتح عند اختيار طالب معين من الجدول لعرض بياناته الأكاديمية والشخصية الكاملة:
* **الهيدر العلوي وشريط الرجوع:**
  * زر رجوع تفاعلي: `← العودة لسجل الطلاب`.
  * الاسم الكامل للطالب بخط عريض (مثل: *أحمد محمود العلي*).
  * رقم الجلوس وكود القيد الدراسي.
  * أزرار التحكم العليا الخاصة بالطالب:
    * زر أحمر: `حذف سجل الطالب`.
    * زر شفاف بحدود: `نقل الطالب لشعبة أخرى`.
    * زر بنفسجي: `تعديل البيانات الأساسية`.
* **شبكة البيانات الثنائية (2 Column Cards Grid):**
  1. **بطاقة البيانات الأكاديمية والحالة الدراسية:**
     * الصف الدراسي المقيد به (مثل: *الصف الخامس الأساسي*).
     * الشعبة والقاعة الحالية (مثل: *الشعبة 5أ*).
     * حالة القيد الأكاديمي (كبسولة خضراء: *مستمر / منتظم*).
     * تاريخ التسجيل وتاريخ آخر تعديل.
  2. **بطاقة بيانات ولي الأمر والتواصل:**
     * الاسم الكامل لولي الأمر (مثل: *محمود العلي*).
     * رقم هاتف ولي الأمر للطوارئ.
     * صلة القرابة (الأب / الأم / الوكيل الشرعي).
     * العنوان والمدينة.

* **واجهات الـ APIs المستخدمة في موديول الطلاب:**
  * `GET /api/admin/students` (مع فلاتر البحث والصف والشعبة).
  * `POST /api/admin/students` ➔ لتسجيل طالب جديد.
  * `PUT /api/admin/students/:id` ➔ لتحديث بيانات الطالب أو تغيير شعبته وصفه.
  * `DELETE /api/admin/students/:id` ➔ لحذف سجل الطالب.

## 4. الموديول الثالث: منظومة إدارة المعلمين والتكليفات (Teacher Records & Profiles)

### أ. لوحة وسجلات المعلمين العامة (`TeacherRecordsPanel.html`):
* **الترويسة وأزرار الإجراءات:**
  * عنوان *إدارة المعلمين والتكليفات المدرسية*.
  * زر بارز: **`+ إضافة معلم جديد`**.
  * زر تكليف: **`تكليف معلم بمادة 🔗`**.
* **شريط البحث:** بحث فوري باسم المعلم أو اسم المستخدم.
* **جدول المعلمين والتكليفات:**
  * الأعمدة: `الاسم الكامل للمعلم` | `اسم المستخدم (Username)` | `التكليفات المسندة (عدد المواد والشعب)` | `إجراءات الإدارة`.
  * **سيناريو النقر على المعلم:** عند الضغط على اسم أي معلم، يتم فتح **الملف الأكاديمي للمعلم (Teacher Profile View)**.
  * أزرار الإجراءات لكل معلم:
    * زر `تكليف 🔗`: لفتح نافذة إسناد مادة وشعبة جديدة له فوراً.
    * زر `حذف المعلم 🗑️`: لحذف حسابه وإلغاء ارتباطاته.

---

### ب. شاشة الملف الأكاديمي للمعلم (`TeacherProfile.html`):
تفتح عند اختيار معلم محدد لعرض بياناته الأكاديمية وحصصه وتكليفاته:
* **الهيدر وبانر المعلم (Hero Banner):**
  * زر عودة: `← العودة لقائمة المعلمين`.
  * اسم المعلم بخط عريض (مثل: *أ. أحمد سالم*) مع صفته الأكاديمية (مثل: *أستاذ مادة الرياضيات*).
  * اسم المستخدم الخاص به (مثل: `teacher2`).
  * كبسولة إجمالي الفصول المكلف بها (مثل: *3 فصول دراسية مسندة*).
  * أزرار التحكم: `+ تكليف بمادة جديدة` و `حذف حساب المعلم`.
* **شبكة البيانات الثنائية:**
  1. **بطاقة بيانات الحساب والكادر التدريسي:**
     * الاسم الكامل واسم المستخدم.
     * التخصص الأكاديمي.
     * حالة الحساب (كبسولة خضراء: *🟢 مفعل ونشط*).
     * تاريخ الانضمام للمؤسسة.
  2. **بطاقة قائمة التكليفات الأكاديمية المسندة:**
     * جدول يعرض كافة المواد والشعب التي يدرسها هذا المعلم:
       * مثال: مادة *الرياضيات* - *الصف الخامس (الشعبة 5أ)*.
       * مثال: مادة *الرياضيات* - *الصف الخامس (الشعبة 5ب)*.
     * زر أحمر صغير `إزالة` بجانب كل تكليف لإلغاء تدريسه لتلك الشعبة دون حذف حسابه.

* **واجهات الـ APIs المستخدمة في موديول المعلمين:**
  * `GET /api/admin/teachers` ➔ لجلب قائمة المعلمين.
  * `POST /api/admin/teachers` ➔ لإنشاء حساب معلم جديد.
  * `DELETE /api/admin/teachers/:id` ➔ لحذف حساب المعلم.
  * `GET /api/admin/assignments` ➔ لجلب قائمة التكليفات المسندة.
  * `POST /api/admin/assignments` ➔ لإسناد تكليف جديد للمعلم.
  * `DELETE /api/admin/assignments/:id` ➔ لإلغاء تكليف محدد.

## 5. الموديول الرابع: منظومة الهيكل والفصول والقاعات (`GradesPanel/`)

يتكون من 3 مستويات تفصيلية مترابطة (المستويات العامة ➔ تفاصيل الصف ➔ تفاصيل الشعبة والجدول):

### أ. لوحة الهيكل والصفوف العامة (`GradesAndClassesPanel.html`):
* **الترويسة والأزرار:** `+ إضافة صف دراسي` | `+ إضافة شعبة 🏢` | `+ إضافة مادة 📖`.
* **جدول المستويات والصفوف (1 إلى 9):**
  * عمود الصف الدراسي (مثل: *الصف الأول* ... *الصف الخامس*).
  * عمود الشعب التابعة (يعرض كبسولات الشعب المنشأة مثل: `5أ`, `5ب`, `5ج`).
  * **سيناريو النقر الأول:** عند النقر على اسم **الصف** ➔ يتم فتح **لوحة تفاصيل الصف الدراسي (Grade Details Panel)**.
  * **سيناريو النقر الثاني:** عند النقر على كبسولة **الشعبة** (مثل `5أ`) ➔ يتم فتح **لوحة تفاصيل الشعبة والجدول (Class Details Panel)**.

---

### ب. لوحة تفاصيل الصف الدراسي (`GradeDetailsPanel.html`):
تفتح عند اختيار صف محدد (مثل *الصف الخامس*):
* **بانر الصف والملخص:**
  * زر رجوع: `← العودة لقائمة الصفوف`.
  * عنوان: *بيانات وتفاصيل: الصف الخامس*.
  * إحصائيات سريعة: عدد الشعب المنشأة، عدد المواد المقررة، وإجمالي الطلاب المقيدين بهذا الصف.
* **القسم الأوسط (بطاقتان متجاورتان):**
  1. **بطاقة الشعب والقاعات المنشأة:**
     * كبسولات الشعب التفاعلية (`5أ`, `5ب`) مع زر سريع `+ إضافة شعبة جديدة لهذا الصف`.
  2. **بطاقة المواد الدراسية المقررة:**
     * جدول يعرض المواد الـ 6 المعتمدة للصف الخامس مع أسماء معلميها وزر `حذف المادة`.
     * زر `+ إضافة مادة مقررة جديدة`.
* **بطاقة سجل الطلاب المقيدين بهذا الصف حصراً:**
  * جدول يعرض طلاب الصف الخامس بجميع شعبه مع أزرار النقل، التعديل، والحذف.

---

### ج. لوحة تفاصيل الشعبة وجدول الحصص (`ClassDetailsPanel.html`):
تفتح عند اختيار شعبة محددة (مثل *الشعبة 5أ*):
* **الترويسة والكبسولات:** عنوان *تفاصيل الشعبة 5أ* + كبسولات الحالة (*6 حصص يومياً*, *شعبة نشطة*).
* **شريط التبويبات الداخلية للشعبة:**
  1. **تبويب الجدول الأسبوعي لشعبة 5أ (نشط):**
     * يعرض شبكة الحصص الأسبوعية (من الأحد إلى الخميس × 6 حصص يومياً).
     * كل خانة حصة منقطة (`Dashed Box`) تعرض: اسم المادة واسم المعلم المخصص.
     * النقر على أي حصة يفتح **نافذة تخصيص/تعديل الحصة** لاختيار المادة والمعلم.
  2. **تبويب الطلاب المسجلون بالشعبة:** قائمة الطلاب المقيدين في شعبة 5أ فقط.
  3. **تبويب المعلمون المكلفون بالشعبة:** قائمة الأساتذة الذين يدرسون مواد في شعبة 5أ.

* **واجهات الـ APIs المستخدمة في موديول الهيكل:**
  * `GET /api/admin/grades` ➔ لجلب الهيكل بالكامل.
  * `POST /api/admin/grades` & `POST /api/admin/sections` & `POST /api/admin/subjects`.
  * `DELETE /api/admin/sections/:id` & `DELETE /api/admin/subjects/:id`.
  * `GET /api/admin/schedule?section_id=X` ➔ لجلب جدول الشعبة.
  * `POST /api/admin/schedule` ➔ لتخصيص أو تحديث حصة في الجدول.
  * `DELETE /api/admin/schedule/:id` ➔ لتفريغ حصة.

## 6. نظام النوافذ المنبثقة التفاعلية (Dialog Modals Specification)

كافة النوافذ المنبثقة مصممة بخلفيات زجاجية ضبابية (`backdrop-filter: blur(8px)`) وزوايا دائرية `20px`:

| النافذة المنبثقة | الحقول والمدخلات | الإجراء والـ API |
| :--- | :--- | :--- |
| **نافذة إضافة صف** | اسم الصف (مثل: الصف الأول)، رقم المستوى (1-9). | `POST /api/admin/grades` |
| **نافذة إضافة شعبة** | اختيار الصف، إدخال اسم الشعبة (مثل: 5ج). | `POST /api/admin/sections` |
| **نافذة إضافة مادة** | اختيار الصف، إدخال اسم المادة (مثل: الحاسوب). | `POST /api/admin/subjects` |
| **نافذة تسجيل طالب** | الاسم الرباعي، رقم الجلوس، كود الدخول، اختيار الصف والشعبة. | `POST /api/admin/students` |
| **نافذة نقل طالب** | اختيار الصف والشعبة الجديدة للطالب. | `PUT /api/admin/students/:id` |
| **نافذة إنشاء معلم** | الاسم الكامل، اسم المستخدم، كلمة المرور. | `POST /api/admin/teachers` |
| **نافذة تكليف معلم** | اختيار المعلم ➔ اختيار الصف والشعبة ➔ اختيار المادة. | `POST /api/admin/assignments` |
| **نافذة تخصيص حصة** | تحديد اليوم، رقم الحصة، اختيار المادة والمعلم المكلف. | `POST /api/admin/schedule` (Upsert) |
