# دليل ومواصفات بوابة تسجيل الدخول الموحدة (Authentication Frontend Specification)

> **المرجع البصري والتنفيذي:** شاشة دخول مركزية موحدة (`/login`) توفر واجهة تفاعلية سهلة، سريعة، وأنيقة تتيح التبديل الفوري بين أدوار النظام الثلاثة (الطالب، المعلم، الإدارة) مع إدارة وتخزين جلسات الـ JWT وتوجيه كل مستخدم لواجهته المخصصة.

---

## 1. الهيكل البصري والتصميم العام (Visual Architecture & Layout)

* **الخلفية العامة للصفحة (`.login-page`):**
  * تدرج لوني ناعم ومريح للعين: `linear-gradient(135deg, #eef2ff 0%, #e0e7ff 100%)`.
  * توسيط كامل للبطاقة في منتصف الشاشة عمودياً وأفقياً (`min-height: 100vh`).
* **بطاقة الدخول المركزية (`.login-card-wrapper`):**
  * بطاقة بيضاء نقية بعرض أقصى `480px` وزوايا دائرية ملساء `24px` (`border-radius: var(--radius-lg)`).
  * حدود ناعمة بلون `#e0e7ff` وظلال خفيفة ثلاثية الأبعاد (`box-shadow: var(--shadow-lg)`).
  * حركة ظهور ناعمة عند التحميل (`animate-fade-in`).

### أ. الترويسة والشعار التجاري (Login Header & Brand):
* **شعار المنظومة:** أيقونة المدرسة الكبرى `🏫` بحجم بارز `3.5rem`.
* **العنوان الرئيسي:** *مدرستي الذهبية* بلون بنفسجي بارز (`font-weight: 800`).
* **النص الفرعي:** *نظام إدارة المدرسة المرتكز على الطالب*.

---

## 2. شريط اختيار الدور والتبديل التفاعلي (Role Selector Cards)

شبكة كبسولية ثلاثية (`3-Column Grid`) تتيح للمستخدم اختيار صفته بضغطة واحدة:

```
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│        🎒 طالب          │        👨‍🏫 معلم         │        ⚙️ إدارة         │
│     (دخول الطالب)       │      (دخول المعلم)      │      (دخول الإدارة)     │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

* **العنصر النشط (`.role-card.active`):** يتحول لخلفية بنفسجية فاتحة `#eef2ff` مع إطار بنفسجي مميز `#4f46e5` وظل خفيف `box-shadow: 0 4px 10px rgba(79, 70, 229, 0.15)`.
* **سلوك التبديل:** عند النقر على أي دور، يتم تفريغ رسائل الخطأ السابقة وتبديل النموذج المعروض فوراً.

---

## 3. نماذج الإدخال التفصيلية حسب الدور (Role-Specific Login Forms)

---

### 1️⃣ نموذج دخول الطالب (Student Login Form):
* **المدخلات والحقول:**
  1. **رقم الجلوس (`roll_number`):** حقل نصي كبير الحجم (مثال: `1001`).
  2. **كود الطالب الخاص (`student_code`):** حقل سري لكود الطالب (مثال: `ST1001`).
* **كبسولة البيانات التجريبية للمعاينة (Demo Hint Box):**
  * تلميح إرشادي بخلفية صفراء خفيفة: `💡 بيانات الطالب التجريبي: رقم الجلوس 1001 والكود ST1001`.
* **زر الإجراء الرئيسي:**
  * زر بنفسجي عريض بكامل العرض: **`دخول الطالب 🚀`** مزود بمؤشر تحميل تفاعلي (`Loading Spinner`).
* **الـ API المستدعى:**
  * `POST /api/auth/login/student`
  * **Payload:** `{ "roll_number": "1001", "student_code": "ST1001" }`
* **الإجراء بعد نجاح الدخول:**
  * حفظ `res.data.token` في `localStorage.setItem('school_token', ...)`
  * حفظ بيانات الطالب في `localStorage.setItem('school_user', ...)`
  * التوجيه التلقائي الفوري إلى شاشة الطالب: `router.push('/student')`.

---

### 2️⃣ نموذج دخول المعلم (Teacher Login Form):
* **المدخلات والحقول:**
  1. **اسم المستخدم (`username`):** حقل نصي (مثال: `teacher1`).
  2. **كلمة المرور (`password`):** حقل كلمة مرور محمي (مثال: `teacher123`).
* **كبسولة البيانات التجريبية:**
  * `💡 بيانات المعلم التجريبي: اسم المستخدم teacher1 وكلمة المرور teacher123`.
* **زر الإجراء الرئيسي:**
  * زر بنفسجي عريض: **`تسجيل دخول المعلم 🔐`**.
* **الـ API المستدعى:**
  * `POST /api/auth/login/teacher`
  * **Payload:** `{ "username": "teacher1", "password": "teacher123" }`
* **الإجراء بعد نجاح الدخول:**
  * تخزين التوكن وبيانات المعلم ➔ التوجيه التلقائي لشاشة المعلم: `router.push('/teacher')`.

---

### 3️⃣ نموذج دخول الإدارة (Admin Login Form):
* **المدخلات والحقول:**
  1. **اسم المستخدم الإداري (`username`):** حقل نصي (مثال: `admin`).
  2. **كلمة المرور الإدارية (`password`):** حقل كلمة مرور محمي (مثال: `admin123`).
* **كبسولة البيانات التجريبية:**
  * `💡 بيانات الإدارة التجريبية: اسم المستخدم admin وكلمة المرور admin123`.
* **زر الإجراء الرئيسي:**
  * زر بنفسجي عريض: **`تسجيل دخول الإدارة 🔐`**.
* **الـ API المستدعى:**
  * `POST /api/auth/login/admin`
  * **Payload:** `{ "username": "admin", "password": "admin123" }`
* **الإجراء بعد نجاح الدخول:**
  * تخزين التوكن وبيانات المدير ➔ التوجيه التلقائي للوحة تحكم الإدارة: `router.push('/admin')`.

---

## 4. معالجة الأخطاء وتجربة المستخدم (Error Handling & UX Feedback)

1. **شريط الخطأ التفاعلي (`.error-banner`):**
   * في حال عدم تطابق البيانات (مثل خطأ برقم الجلوس أو كلمة المرور)، يظهر شريط أحمر ناعم `#fef2f2` بحدود حمراء `#fecaca` يعرض نص الخطأ الوارد من الخادم (مثال: `⚠️ رقم الجلوس أو كود الطالب غير صحيح.`).
2. **منع الإرسال المتعدد (Debounce & Loading State):**
   * أثناء معالجة الطلب يتم تعطيل زر الدخول وتفعيل مؤشر الدوران لمنع تكرار الضغط.
3. **حماية التوجيه التلقائي (Auto Redirect for Logged-in Users):**
   * إذا كان المستخدم مسجل دخوله مسبقاً ولديه توكن صالح في المتصفح وزار رابط `/login`، يمنعه حارس المسارات (`router.beforeEach`) من رؤية صفحة الدخول ويوجهه فورياً إلى لوحة التحكم الخاصة به (طالب ➔ `/student`، معلم ➔ `/teacher`، إدارة ➔ `/admin`).
