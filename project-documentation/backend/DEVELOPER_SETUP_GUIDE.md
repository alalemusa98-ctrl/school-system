# الدليل الشامل لتثبيت وتشغيل وتطوير الخادم الخلفي (Backend Developer Setup & Execution Guide)

يوفر هذا الدليل المرجع الإجرائي خطوة بخطوة للمطورين أو أنظمة الذكاء الاصطناعي لتهيئة بيئة العمل، تثبيت الاعتماديات، إنشاء وترحيل قاعدة البيانات، تعبئة البيانات التجريبية، وتشغيل وفحص الخادم الخلفي.

---

## 1. المتطلبات الأساسية للنظام (System Prerequisites)

قبل البدء، تأكد من تثبيت الأدوات التالية على بيئة التشغيل الخاصة بك (Windows / macOS / Linux):
* **Node.js:** الإصدار `v18.x` أو `v20.x` LTS أو أحدث.
* **NPM:** الإصدار `v9.x` أو `v10.x` أو أحدث.
* **محرك قاعدة البيانات:**
  * **الافتراضي (مدمج):** لا يتطلب تثبيت أي خادم خارجي، حيث يعمل الخادم فورياً باستخدام `SQLite3`.
  * **الإنتاجي (اختياري):** خادم `MySQL Server 8.0+` أو `MariaDB 10.5+` (في حال تفعيل `DB_DRIVER=mysql`).

---

## 2. خطوات التثبيت والتشغيل المحلي (Step-by-Step Local Setup)

### الخطوة 1: الانتقال إلى مجلد الخادم الخلفي
افتح موجه الأوامر (Terminal / PowerShell) وانتقل إلى مجلد `backend`:
```bash
cd backend
```

---

### الخطوة 2: تثبيت حزم واعتماديات Node.js
قم بتنفيذ الأمر التالي لتثبيت كافة المكتبات (`express`, `sqlite3`, `mysql2`, `jsonwebtoken`, `bcryptjs`, `multer`, `cors`, `dotenv`):
```bash
npm install
```

---

### الخطوة 3: إعداد ملف متغيرات البيئة (`.env`)
تأكد من وجود ملف باسم `.env` في المسار `backend/.env`. وفي حال عدم وجوده، قم بإنشائه بالقيم التالية:

```env
# منفذ الخادم
PORT=5000

# مشغل قاعدة البيانات: sqlite (افتراضي وسريع) أو mysql (للإنتاج)
DB_DRIVER=sqlite

# مفتاح تشفير توكن JWT ومدة الصلاحية
JWT_SECRET=super_secret_school_jwt_key_2026
JWT_EXPIRES_IN=7d

# --- إعدادات إضافية في حال استخدام مشغل MySQL ---
# DB_DRIVER=mysql
# DB_HOST=localhost
# DB_PORT=3306
# DB_USER=root
# DB_PASSWORD=your_mysql_password
# DB_NAME=school_db
```

---

### الخطوة 4: ترحيل قاعدة البيانات وبناء الجداول (Run Migrations)
قم بتشغيل سكريبت إنشاء الجداول الـ 10 بالتسلسل والتكامل المرجعي:

npm run db:migrate

### الخطوة 6: تشغيل خادم التطوير (Start Server)
لتشغيل الخادم مع ميزة التحديث التلقائي عند تعديل الكود:
```bash
npm run dev
```

* سيبدأ الخادم بالاستماع على: **`http://localhost:5000`**
* مجلد المرفقات والملفات الثابتة متاح على: **`http://localhost:5000/uploads`**

## 3. التحقق واختبار الصحة السريع (Smoke Tests & Verification)

### أ. فحص جاهزية الخادم (Health Check):
نفذ طلب GET على الجذر للتأكد من أن الخادم يعمل بكفاءة:
```bash
curl http://localhost:5000/
```
**الاستجابة:**
```json
{
  "success": true,
  "message": "مرحباً بك في الخادم الخلفي لنظام إدارة المدرسة المرتكز على الطالب (V1 MVP)",
  "version": "1.0.0",
  "status": "Running"
}
```

---

### ب. تجربة تسجيل دخول الطالب (Student Login Test):
```bash
curl -X POST http://localhost:5000/api/auth/login/student \
  -H "Content-Type: application/json" \
  -d "{\"roll_number\": \"1001\", \"student_code\": \"ST1001\"}"
```
**الاستجابة:** يعيد كود `200 OK` مع رمز `token` وتفاصيل الطالب (أحمد خالد - شعبة 5أ).

---

### ج. تجربة تسجيل دخول الإدارة (Admin Login Test):
```bash
curl -X POST http://localhost:5000/api/auth/login/admin \
  -H "Content-Type: application/json" \
  -d "{\"username\": \"admin\", \"password\": \"admin123\"}"
```
**الاستجابة:** يعيد كود `200 OK` مع توكن المشرف العام.

## 5. دليل استكشاف الأخطاء وحلها (Troubleshooting & FAQ)

### 1. خطأ تعارض المنفذ `EADDRINUSE: address already in use :::5000`:
* **السبب:** هناك تطبيق آخر أو نسخة سابقة من الخادم تعمل على المنفذ 5000.
* **الحل:**
  * **على نظام Windows:** قم بتشغيل الأمر: `netstat -ano | findstr :5000` ثم إنهاء العملية عبر `taskkill /PID <PID_NUMBER> /F`.
  * **أو بدلاً من ذلك:** قم بتغيير المنفذ في ملف `.env` إلى `PORT=5001`.

### 2. خطأ قفل قاعدة البيانات `SQLITE_BUSY: database is locked`:
* **السبب:** فتح ملف `school.sqlite` عبر برنامج خارجي (مثل DB Browser for SQLite) في وضع القفل أو التعديل المفتوح.
* **الحل:** أغلق برامج استعراض قواعد البيانات الخارجية وأعد تشغيل الخادم.

### 3. إعادة تصفير قاعدة البيانات بالكامل (Database Reset):
* في حال الرغبة في حذف كافة التعديلات والبدء من نقطة الصفر:
```bash
# حذف ملف قاعدة البيانات المحلي
rm database/school.sqlite   # أو على ويندوز: del database\school.sqlite

# إعادة البناء والتعبئة من جديد
npm run db:migrate
npm run db:seed
```

### 4. مشكلة عدم فتح المرفقات أو رفع الملفات:
* تأكد من وجود مجلد `backend/uploads/`. يقوم الخادم بإنشائه تلقائياً عند الإقلاع، ولكن تأكد من امتلاك المستخدم لصلاحيات الكتابة على المجلد.
