## ⚙️ 2. واجهة المكون البرمجية (Props & Emits API)

### أ. الـ Props المدعومة:
| الخاصية (Prop) | النوع | الافتراضي | الوصف |
| :--- | :--- | :--- | :--- |
| `currentTime` | `String` | `'9:41'` | توقيت شريط الحالة بنمط iOS |
| `schoolName` | `String` | `'مدرسة النور الإعدادية'` | اسم المؤسسة التعليمية في شريط التنقل |
| `userName` | `String` | `'أحمد خالد'` | الاسم الرئيسي للمستخدم |
| `userSubtitle` | `String` | `'الصف الخامس'` | النص الفرعي أسفل الاسم (مثلاً: الصف والشعبة أو التخصص) |
| `userTag` | `String` | `''` | شارة نصية إضافية (مثلاً: القسم أو الفصول المسندة) |
| `avatarIcon` | `String` | `'🏫'` | إيموجي أو أيقونة الصورة الرمزية |
| `avatarImage` | `String` | `''` | رابط صورة شخصية في حال توفرها |
| `isOnline` | `Boolean` | `true` | إظهار النقطة الخضراء المتوهجة للحالة النشطة |
| `themeGradient` | `String` | `'purple'` | نمط التدرج للهيدر (`'purple'` أرجواني، `'emerald'` زمردي، `'blue'` أزرق، أو كود تدرج مخصص) |
| `stats` | `Array` | `[...]` | مصفوفة العدادات الثلاثة: `[{ id, label, value, color, icon, route }]` |

### ب. الأحداث المنبعثة (Emits):
* `logout`: يُطلق عند الضغط على زر تسجيل الخروج.
* `open-notifications`: يُطلق عند الضغط على زر التنبيهات.
* `stat-click`: يُطلق عند الضغط على أي عنصر إحصائي مع تمرير كائن العداد `(stat)`.
