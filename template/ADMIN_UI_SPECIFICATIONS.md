# دليل ومواصفات واجهات لوحة التحكم الإدارية (Admin UI Components Specifications & Prompting Guide)

هذا المستند الشامل يحتوي على الوصف الفني والتفصيلي لكافة واجهات، مكونات، بطاقات، جداول، وأزرار **منظومة إدارة المدرسة (Admin Dashboard)**. تم إعداده خصيصاً ليتم تزويده لنماذج الذكاء الاصطناعي (AI / LLM) لبناء وتوليد الواجهات بدقة بصرية 100% دون أي نقص.

---

## 🎨 1. الدستور البصري ونظام التصميم العام (Global Design System)

* **اتجاه الصفحة (Direction):** `RTL` (يمين إلى يسار كلياً).
* **خط النص الإلزامي (Typography Stack):** خط أبل العربي الرسمي `SF Arabic` / `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", sans-serif`.
* **نظام الأيقونات (Iconography):** استخدام حصري لأيقونات الفكتور الموجهة (`SVG Vector Icons`) بنمط `stroke` خفيف وسلس، ويُمنع استخدام الإيموجي (Emojis).
* **لوحة الألوان (Color Palette):**
  - **اللون الرئيسي (Primary Indigo):** `#4f46e5` تدرج إلى `#4338ca`.
  - **الخلفية العامة (Background):** `#f8fafc`.
  - **الأسطح والبطاقات (Surface):** `#ffffff` بحدود ملساء `#e2e8f0` وزوايا دائرية `20px` إلى `24px` وظلال ناعمة `box-shadow: 0 12px 36px rgba(15, 23, 42, 0.04)`.
  - **النصوص الرئيسية:** `#0f172a` (داكن شديد الوضوح).
  - **النصوص الثانوية:** `#64748b` (رمادي ناعم).
  - **حالة النجاح (Success Emerald):** `#10b981` / `#dcfce7`.
  - **حالة الخطر/الحذف (Danger Rose/Red):** `#ef4444` / `#fff1f2`.
  - **الكبسولات التفاعلية (Badges):** `#eef2ff` بنص `#4338ca`.

## 🏛️ 2. الهيدر التنفيذي وشريط التنقل العلوي (`header.html`)

### الوصف والمكونات:
1. **الشعار والعنوان التجاري (Brand Header):**
   - مربع متدرج بنفسجي بداخل أيقونة قبعة التخرج SVG + عنوان `منظومة إدارة المدرسة` ونص فرعي `لوحة التحكم الإدارية الشاملة`.
2. **شريط البحث المركزي السريع (Global Search):**
   - حقل بحث محاط بإطار دائر `border-radius: 40px` وخلفية ناعمة مع أيقونة عدسة مكبرة SVG وخيار البحث الفوري.
3. **التنبيهات وجرس الإشعارات (Notifications Bell):**
   - زر دائر يحتوي على جرس إشعارات SVG ومؤشر أحمر بعدد التنبيهات النشطة.
4. **القائمة المنسدلة النمطية لـ macOS (Profile Dropdown):**
   - كبسولة تحتوي على صورة الرمز التعبيري لمدير المنظومة، الاسم، والصفة مع سهم منسدل.
   - عند الضغط تفتح قائمة عائمة بخلفية زجاجية (`backdrop-filter: blur`) تظهر بيانات الحساب الاختصارات السريعة (`⌘1`, `⌘2`) وزر تسجيل الخروج الأحمر (`⌥⌘Q`).
5. **شريط التنقل الأفق الأفقي (Minimal Sub-Navbar):**
   - روابط تنقل أفقية بكبسولات تفاعلية: `الرئيسية`, `الطلاب`, `المعلمون`, `الفصول`, `المواد الدراسية`, `الجدول الدراسي`, `الواجبات`, `الامتحانات`, `التقارير`, `الإعدادات`.

## 📊 3. بطاقات الإحصائيات ثلاثية الأبعاد (`metric_cards.html` & `card.html`)

### الوصف والمكونات:
* **شبكة بطاقات الـ 3D KPI (4 بطاقات رئيسية):**
  - **بطاقة حضور الطلاب:** خلفية زمردية ناعمة `#f7fdf9` وحدود خضراء `rgba(52, 199, 89, 0.22)`.
  - **بطاقة حضور المعلمين:** خلفية زمردية ناعمة `#f7fdf9`.
  - **بطاقة الواجبات والتكليفات:** خلفية بنفسجية ناعمة `#faf7fd`.
  - **بطاقة الامتحانات والتقييمات:** خلفية برتقالية ناعمة `#fdfbf7`.
* **بنية البطاقة الواحدة (`.card-3d-box`):**
  - **الترويسة:** العنوان البارز (يمين) + كبسولة أيقونة الفكتور SVG (يسار).
  - **الجسم الداخلي (`.card-3d-body` مع `flex-direction: row-reverse`):**
    - اليمين: الرقم العريض مثل (`184,192`) متبوعاً بالوحدة (`طالب`).
    - اليسار: صورة المجسم ثلاثي الأبعاد الأصلي (`student_attendance_3d.png`) مع الظل البيضاوي الناعم في الأسفل.
  - **شريط التقدم:** خط تقدم متدرج زمردي/بنفسجي/برتقالي.
  - **الشريط السفلي:** مؤشرات الحضور والغياب (نقطة خضراء `🟢 الحضور` ونقطة حمراء `🔴 الغياب`).

## ⚙️ 4. شريط التاريخ وإجراءات الصفحة (`PageActions.html`)

### الوصف والمكونات:
* **كبسولة التاريخ اليومي (`.saas-date-pill`):**
  - أيقونة تقويم متجهة SVG + نص `اليوم: الجمعة، 16 أغسطس 2026`.
* **زر طباعة التقرير اليومي (`.saas-print-btn`):**
  - زر بخلفية بيضاء ونص وبنفسجي مجهز بأيقونة طابعة متجهة SVG يربط حدث الطباعة المباشر (`window.print()`).

## 🎓 5. منظومة إدارة الطلاب (`template/admin/student/`)

### أ. لوحة وسجلات الطلاب (`StudentRecordsPanel.html`)
* **الترويسة:** عنوان `إدارة سجلات وحسابات الطلاب` + أيقونة قبعة التخرج SVG + أزرار الإجراءات العليا: `+ إضافة طالب جديد` (بنفسجي رئيسي) وزر `نقل طالب` (أبيض ذو حدود).
* **شريط الفلاتر والبحث:**
  - حقل بحث دائري `بحث باسم الطالب، كود الطالب...`.
  - فلتر القائمة المنسدلة `جميع الصفوف` مجهز بأيقونة فكتور بحجم `25px`.
  - فلتر القائمة المنسدلة `جميع الشعب` مجهز بأيقونة فكتور بحجم `25px`.
* **جدول البيانات:**
  - الأعمدة: `رقم الجلوس` | `كود الطالب` | `الاسم الكامل للطالب` | `الصف الدراسي` | `الشعبة` | `إجراءات الإدارة`.
  - الأزرار لكل صف: زر النقل (`🔄`), زر التعديل (`✏️`), زر الحذف (`🗑️`).
  - فلترة وتصفية تفاعلية فورية بـ Vanilla JS.

### ب. ملف الطالب التفصيلي (`StudentProfile.html`)
* **الترويسة:** زر عودة `← العودة لسجل الطلاب` + اسم الطالب `أحمد محمود العلي` + الكود والقيد + أزرار: `حذف الطالب` (أحمر خطر), `نقل الطالب` (شفاف), `تعديل البيانات` (بنفسجي).
* **شبكة البيانات الثنائية (2 Columns):**
  - **بطاقة البيانات الأكاديمية:** الصف الدراسي، الشعبة، حالة القيد (`مستمر / منتظم`), تاريخ التسجيل.
  - **بطاقة بيانات ولي الأمر والتواصل:** اسم ولي الأمر، رقم الهاتف، صلة القرابة، والعنوان.

## 👨‍🏫 6. منظومة إدارة المعلمين والتكليفات (`template/admin/teacher/`)

### أ. لوحة وسجلات المعلمين (`TeacherRecordsPanel.html`)
* **الترويسة:** عنوان `إدارة المعلمين والتكليفات المدرسية` + أيقونة معلم SVG + أزرار: `+ إضافة معلم جديد` و `تكليف معلم بالمادة 🔗`.
* **حقل البحث:** مربع بحث جهة اليمين `بحث باسم المعلم أو اسم`.
* **جدول المعلمين:**
  - الأعمدة: `الاسم الكامل للمعلم` | `اسم المستخدم` | `التكليفات المسندة` | `إجراءات الإدارة`.
  - الأزرار لكل معلم: زر `تكليف 🔗` (أبيض ذو حدود بنفسجية) وزر `حذف المعلم` (أحمر ذو حدود ملساء).

### ب. ملف المعلم الأكاديمي (`TeacherProfile.html`)
* **الترويسة والـ Hero Banner:** زر عودة `← العودة لقائمة المعلمين` + اسم المعلم `أ. أحمد سالم` + اسم المستخدم `teacher2` + عدد التكليفات المسندة + أزرار: `تكليف بمادة جديدة` و `حذف حساب المعلم`.
* **شبكة البيانات الثنائية:**
  - **بطاقة بيانات الحساب والكادر:** الاسم الكامل، اسم المستخدم، الصفة الأكاديمية، وحالة الصلاحيات (`🟢 مفعل`).
  - **بطاقة التكليفات الأكاديمية المسندة:** جدول المواد المسندة (مثل `الرياضيات` - `الصف الخامس أ5`) مع زر `إزالة` لكل مادة.

## 🏫 7. منظومة الفصول الهيكل التعليمي (`template/admin/GradesPanel/`)

### أ. لوحة الهيكل التعليمي والصفوف (`GradesAndClassesPanel.html`)
* **الترويسة:** عنوان `الهيكل التعليمي والفصول الدراسية` + قبعة تخرج SVG + أزرار: `+ إضافة صف دراسي`, `إضافة شعبة 🏢`, `إضافة مادة 📖`.
* **جدول المستويات (صفوف 1 - 9):**
  - الأعمدة: `الصف الدراسي (اضغط للتفاصيل)` | `الشعب والقاعات الدراسية (اضغط للتفاصيل والجدول)`.
  - يعرض كبسولات الشعب المنشأة (مثل `الشعبة 5أ`, `الشعبة 5ب`) أو النص الرمادي `لا توجد شعب منشأة`.

### ب. تفاصيل الصف الدراسي (`GradeDetailsPanel.html`)
* **الترويسة والـ Hero Banner:** زر عودة + عنوان `بيانات وتفاصيل: الصف الخامس` + ملخص المستويات والشعب والمواد والطلاب.
* **القسم الأوسط (2 Columns):**
  - **بطاقة الشعب والقاعات المنشأة:** عرض كبسولات الشعب التفاعلية مع زر `إضافة شعبة`.
  - **بطاقة المواد الدراسية المقررة:** جدول المواد الـ 6 مع زر `حذف المادة`.
* **بطاقة سجل الطلاب المقيدين بالصف:** جدول مكتمل للطلاب مع أزرار النقل، التعديل، والحذف.

### ج. تفاصيل الشعبة والجدول الأسبوعي (`ClassDetailsPanel.html`)
* **الترويسة والكبسولات:** عنوان `تفاصيل الشعبة 5أ` + كبسولات حالة الشعبة (`5 حصص يومياً`, `شعبة مفعلة ونشطة`).
* **شريط التبويبات التفاعلية (Tabs):**
  - `الجدول الأسبوعي لشعبة 5أ (من الأحد للخميس - 6 حصص يومياً)` (نشط).
  - `الطلاب المسجلون (1)`.
  - `المعلمون المكلفون (6)`.
  - `الجدول الدراسي (الافتراضية)`.
* **شبكة الجدول الأسبوعي (Timetable Grid):**
  - 5 أيام (الأحد ➔ الخميس) x 6 حصص (الحصة 1 ➔ الحصة 6).
  - مربعات الحصص المنقطة (`Dashed Lesson Boxes`) تحتوي على اسم المادة واسم المعلم المخصص بكل حصة.

## 🪟 8. نظام النوافذ المنبثقة (Dialog Modals System)

* **التصميم العام للـ Modal:**
  - خلفية معتمة بخلفية ضبابية زجاجية (`backdrop-filter: blur(6px)`).
  - نافذة بيضاء بزوايا دائرية `20px` وحدود ناعمة.
  - ترويسة مع العنوان وأيقونة إغلاق `✕`.
  - حقول الإدخال والقوائم المنسدلة الملساء.
  - أزرار الحفظ والإلغاء في شريط الإغلاق السفلي.
